# WIN Monitor

Sistema de apoio ao estudo de day trade no Mini Índice (WIN).

O projeto captura a tela com os gráficos M60, M15 e M5, classifica cenários em `ENTRADA`, `QUASE` ou `SEM_SETUP`, registra evidências e envia alertas via Telegram. Nesta fase, não executa ordens.

## Estado

Repositório inicializado para receber o monitor de estudo, testes, configuração segura e empacotamento para Windows.
